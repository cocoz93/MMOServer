# 인포그래픽 소스 (`_src`)

상위 폴더(`8.JOINLEAVE 팬아웃 중복 제거`)에 들어가는 **설명 이미지 2장의 편집 가능한 소스**.
HTML/CSS/SVG → 헤드리스 Chrome 4배(4x) 캡처 → PNG. 폰트는 Pretendard(`fonts/`) 임베드.
톤은 `img/1. SendQ LockFree…/_src`(플랫 데이터-viz 카드)를 클론 — 팔레트·카드·그림자·푸터 동일.

## 2장 구성 (읽는 순서 = 이야기 흐름)

| 최종 PNG (상위 폴더) | HTML | 논리크기→4x | 메시지 |
|---|---|---|---|
| `01_sector_stage.png` | `s1.html` | 1200×660 | 무대 — 한 칸 넘으면 시야 9섹터가 밀려 3섹터가 빠지고 3섹터가 들어온다. 그 칸을 열면 나가는 건 전부 같은 내용, 들어오는 건 전부 다른 내용 |
| `02_fold_p1_p2.png` | `s2.html` | 1200×660 | 무엇이 1이 되는가 — P1은 **상자만** 1개(선은 N개 그대로), P2는 **상자도 선도** 1개. 그래서 P2가 더 크게 접힌다 |

노션 배치는 1장 → 2절 도입, 2장 → 3절 앞.

### 갈아엎기 전 5장 세트 (2026-08-08 폐기)
`01.html`~`05.html`과 `01_bottleneck_54pct.png`~`05_result_68pct.png`은 디스크에만 남겨둔 옛 버전이다.
빌드 대상에서 빠졌다. 폐기 사유 — ① 무대(섹터·시야)가 없어 추상 원·카드뿐이었고,
② 제목·본문 표에 이미 있는 숫자를 옮기기만 해 정보를 더하지 않았으며,
③ P1과 P2가 같은 템플릿이라 "무엇이 1이 되는가"라는 둘의 결정적 차이가 사라졌다.

## 디자인 시스템 (2장 공통)
- 폰트 Pretendard(`fonts/PretendardVariable.woff2`, 가변). `--allow-file-access-from-files` 필수(빠지면 Malgun 폴백).
- 팔레트: bg `#eef1f5` · 카드 `#fff` · 잉크 `#1f2330` · 빨강 `#d7263d`/딥 `#b3122a` · 파랑 `#3a78b8`/`#2b6aa8`.
  - **파랑=아웃바운드/P1, 빨강=인바운드/P2**. 무대(s1)에서 빠지는 섹터는 흐린 회색, 들어온 섹터는 빨강 — 색이 아니라 명도로 구분.
  - s1 확대 패널은 **색으로 "같다/다르다"를 말한다** — 나가는 쪽은 상대 원이 전부 무채색이고 선·봉투가
    같은 파랑(수신자를 가릴 필요가 없다, 내용이 하나). 들어오는 쪽은 **상대마다 고유색**을 주고
    그 사람의 원·선·촉·봉투를 한 색으로 묶는다(각자 자기 정보를 보낸다).
    - 고유색 4종 `#d7263d` 빨강 · `#c0782c` 황토 · `#3d8a7c` 청록 · `#8a5091` 자주.
      **채도·명도는 맞추고 색상만 벌린다** — 빨강 2종+회색 2종처럼 같은 계열로 묶으면 실질 2색이라
      "제각각"이 느껴지지 않는다(실제로 그렇게 만들었다 반려됨). 파랑은 아웃바운드 전용이라 쓰지 않는다.
- 카드: 캔버스 24px 여백 → 흰 카드 radius 30, 그림자 2겹, 상단 제목+빨강 밑줄+회색 부제, 하단 얇은 푸터 1줄.
- 부채꼴 팬아웃에서 **패킷 상자는 선 중간에 두지 말 것** — 중간점이 한 점에 뭉쳐 기둥 하나로 보인다.
  선 위 t≈0.75(먼 쪽) 지점에 놓아 벌리고, "1개에서 N개가 갈라지는" 그림은 선 시작을 상자 중심에 두어
  상자가 선머리를 덮게 한다(상자 밖에서 시작하면 쐐기처럼 찌르는 모양이 됨).
- **수렴하는 선(N→1)에는 끝 화살촉을 달지 말 것** — 끝점이 한 점에 모이므로 촉 4개가 겹쳐
  도착 지점에 뾰족한 덩어리가 생긴다(원과 같은 색이면 원이 찌그러져 보임). 방향 표시는 아직 선이
  벌어져 있는 자리(상자 뒤 t≈0.5)에 삼각형으로 따로 놓고, 촉 색은 선 색과 맞춘다.
- 좌우 배치가 곧 방향이다 — **나가는 것은 나(왼)→여럿(오), 들어오는 것은 여럿(왼)→나(오)**.
  둘 다 나를 왼쪽에 두고 화살표만 뒤집으면 "들어온다"가 읽히지 않는다(눈은 좌→우로 읽는다).
- HTML은 UTF-8(BOM 불필요, `<meta charset=utf-8>`). 상위 `*.png`는 레포 `.gitignore`로 추적 안 됨(디스크에만).

## 코드 근거 (도식이 어긋나지 않게)
- 시야 = `CSectorManager::MAX_AROUND_SECTORS = 9` (3×3).
- `GetSectorDiff(old, new, added, removed)` = old 3×3과 new 3×3의 차집합 → 한 칸 이동이면 **3섹터 빠지고 3섹터 들어옴**.
- `ProcessSectorChange` — 이탈 섹터는 상호 DELETE, 진입 섹터는 상호 CREATE.
  아웃바운드는 `FanoutToSectors`(P1), 인바운드는 `SendCreatePlayerBatch`/`SendDeletePlayerBatch`(P2).
